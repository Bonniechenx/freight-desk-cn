# 运费核算台

面向快递、电商与云仓的纯前端运费计算工具，支持单票试算、XLSX/XLS/CSV 批量核算、报价规则配置、地区附加费、店铺绑定和 CSV 结果导出。

同一报价表可以按物流公司或报价条件、生效日期、目的地和重量保存多组价格，并识别“加收费用”Sheet；批量账单上传后可自由映射目的地组合列和计费列。

可同时导入多份报价，并通过任意数量的自定义结算条件联合匹配报价，例如“所属客户 + 店铺名称”或“货主 + 平台 + 仓库 + 物流公司”。

批量计算完成后会自动保存在浏览器本机数据库中。导出结果会保留原表全部列，并在右侧追加基础费、各项加收费、抵扣、合计和核算说明。

在线使用：<https://bonniechenx.github.io/freight-desk-cn/>

## 隐私

账单解析、运费计算和配置保存均在浏览器本地完成，应用没有后端数据库，也不会主动上传用户导入的业务数据。清理浏览器站点数据会删除本机保存的配置。
